# ARTIS Invoice Desktop

[English guide](README.md)

برنامهٔ رومیزی ویندوز برای ساخت پیش‌فاکتور با اطلاعات مشتری و کالا. رابط کاربری با Tkinter، داده‌ها با SQLite و فایل اکسل با `openpyxl` ساخته می‌شود. خروجی PDF به Microsoft Excel روی ویندوز وابسته است.

## امکانات بررسی‌شده در کد

- بخش‌های فاکتور، مشتری، کالا و جستجو
- ثبت مشتری و کالا در پایگاه دادهٔ محلی
- ساخت اکسل با دو قالب خالی آبی و قرمز
- پشتیبانی از ۱۶ ردیف کالا در نسخهٔ آماده‌شده؛ نگاشت نسخهٔ اولیه فقط ردیف اول را پر می‌کرد
- خروجی PDF با Excel COM

## اجرا

Windows، Python 3.13 و برای خروجی PDF، Microsoft Excel لازم است.

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python invoice_app/main.py
```

پایگاه داده و خروجی‌ها هنگام استفاده ساخته می‌شوند و نباید همراه اطلاعات مشتری در Git ثبت شوند.

## حق انتشار قالب‌ها

قالب‌های اولیه بر پایهٔ فایل‌های Vertex42 بودند و در این نسخه قرار نگرفته‌اند. فایل‌های `invoice_app/templates/` از ابتدا برای این پیش‌نویس ساخته شده‌اند و همان آدرس سلول‌های موردنیاز برنامه را دارند. ظاهر و خروجی PDF باید روی سیستم دارای Excel بررسی شود. این نسخه با مجوز MIT منتشر می‌شود.
